# Build-Status

Die Projektdateien sind vollständig angelegt. Ein `npm install` konnte in der Sandbox wegen fehlendem/zu langsamem externem Netzwerk nicht abgeschlossen werden; deshalb konnte hier kein Vite-Produktionsbuild erzeugt werden. Lokal mit Node.js 20+ genügt:

```bash
npm install
npm run build
```
